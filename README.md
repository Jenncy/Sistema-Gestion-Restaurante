# Sistema de Gestión de Restaurante

Aplicación de escritorio desarrollada en C# y Windows Forms para gestionar órdenes y calcular totales de consumo en un restaurante.

## Funcionalidades

- Registro de productos y cantidades
- Creación de órdenes
- Cálculo del total de la orden
- Limpieza para iniciar una nueva orden

## Tecnologías

- C#
- .NET
- Windows Forms

## Ejecución

1. Clona el repositorio.
2. Abre `Proyecto_Restaurante.sln` en Visual Studio.
3. Compila la solución.
4. Ejecuta el proyecto.
